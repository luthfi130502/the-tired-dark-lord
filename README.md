## What it does

`main.py` (Python 3.13, standard library only) writes one monologue to
`/output/entry.txt`: Vesskar, the Pale Steward of Tarrow, has rung the
dawn bell for a king three hundred years dead. On the longest night he
will ring all seven bells together and wake him — not for the throne,
but so someone else can finally hold it. The tiredness is never named;
it lives in the repetitions, the lost thread, and a chair by the east
window he has never once sat in.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
